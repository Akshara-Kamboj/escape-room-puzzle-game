# 🔐 Escape Room Puzzle Game

**Think Fast. Solve the Mystery. Escape Before Time Runs Out.**

An interactive, browser-based Escape Room Puzzle Game where players solve riddles, uncover clues, and challenge their logical thinking against a countdown timer. Choose your difficulty, solve puzzles, use hints strategically, and see if you can escape before time runs out!

---

## 📌 About the Project

Escape Room Puzzle Game is a frontend-based web application designed to provide an engaging puzzle-solving experience through interactive riddles and time-based challenges.

Players enter a virtual escape room where they must solve a sequence of puzzles to complete the game. Each difficulty level offers a different challenge and time limit, making the experience suitable for beginners as well as experienced puzzle enthusiasts.

The project focuses on combining logical reasoning, problem-solving, interactive web development, and an engaging user interface.

## ✨ Key Features

- **Three Difficulty Levels:** Choose between Easy, Medium, and Hard.
- **Level-Based Riddles:** Different puzzles tailored to each difficulty.
- **Countdown Timer:** Race against time to solve all the riddles.
- **Interactive Gameplay:** Submit answers and receive instant feedback.
- **Hint System:** Get clues when you need help solving a puzzle.
- **Score Tracking:** Track your performance throughout the game.
- **Progress Tracking:** Monitor the number of puzzles solved.
- **Multiple Themes:** Customize the appearance of the game.
- **Victory and Game Over Screens:** Get feedback based on your performance.
- **Replay Functionality:** Start a fresh game or try another difficulty.
- **Responsive Design:** Play across desktop, tablet, and mobile devices.

## 🎮 Difficulty Levels

| Level | Time Limit | Challenge |
|---|---:|---|
| 🟢 Easy | 4 Minutes | Beginner-friendly riddles |
| 🟣 Medium | 6 Minutes | Logical thinking and pattern recognition |
| 🔴 Hard | 8 Minutes | Advanced reasoning and challenging riddles |

Each level offers a separate collection of puzzles designed according to its difficulty.

## 🕹️ How to Play

1. Open the game in your web browser.
2. Choose your preferred difficulty level.
3. Click **Start Game** to begin the challenge.
4. Read the riddle displayed on the screen.
5. Enter your answer and submit it.
6. Use hints strategically if you get stuck.
7. Solve all the puzzles before the countdown reaches zero.
8. Complete the challenge and reach the Victory screen!

**Remember:** Every second counts. Think carefully and make your moves wisely!

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
- Visual Studio Code (recommended).
- Live Server extension for VS Code (recommended).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Akshara-Kamboj/escape-room-puzzle-game.git
```

**2. Navigate to the project directory**

```bash
cd escape-room-puzzle-game
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

**4. Run the application**

- Open `index.html` in Visual Studio Code.
- Right-click the file.
- Select **Open with Live Server**.

Alternatively, open `index.html` directly in your browser if the project does not require a local server.
